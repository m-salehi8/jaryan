# ۱۵. واژه‌نامه و اصطلاحات

## اصطلاحات فارسی سیستم

| اصطلاح فارسی | معادل انگلیسی | توضیح |
|-------------|--------------|-------|
| جریان | Jaryan | نام برند پلتفرم |
| فرایند | Workflow | یک جریان کاری با node و edge |
| نمونه فرایند | Process Instance | یک اجرای خاص از workflow |
| تسک / وظیفه | Task | یک کار قابل انجام در یک مرحله از فرایند |
| تاییدیه | Approval | نوعی تسک که نیاز به تایید یا رد دارد |
| کارتابل | Inbox | لیست تسک‌های کاربر |
| گره | Node | یک مرحله در workflow |
| لبه | Edge | ارتباط بین دو node |
| نقطه شروع | Trigger | اولین node هر workflow |
| شرط | Condition | قانون ارزیابی‌شده برای انتخاب مسیر |
| گیت | Gate | node condition که مسیر را تعیین می‌کند |
| مهلت | Deadline | زمان پایان مجاز برای انجام تسک |
| دیرکرد | Overdue | تسکی که از مهلت گذشته |
| ارجاع | Escalation | انتقال تسک به مدیر هنگام timeout |
| سازمان | Organization | یک tenant مستقل در سیستم |
| دپارتمان | Department | بخش/واحد سازمانی |
| طراح فرایند | Process Designer | نقش کاربر برای ساختن workflow |
| ادمین سازمان | Org Admin | مدیر ارشد سازمان در سیستم |
| تنخواه | Petty Cash | درخواست پرداخت پیش‌پرداخت |
| مأموریت | Business Trip | سفر اداری |
| آنبوردینگ | Onboarding | فرایند جذب و معارفه کارمند جدید |
| کارتابل | Inbox | صفحه مدیریت تسک‌های کاربر |
| نمودار سازمانی | Org Chart | نمایش بصری ساختار سازمان |

## اصطلاحات فنی

| اصطلاح | توضیح |
|--------|-------|
| **Multi-Tenant** | هر سازمان داده‌های کاملاً مجزا دارد (ایزولاسیون با `org_id`) |
| **BFS** | Breadth-First Search - الگوریتم پیمایش گراف در engine |
| **SSE** | Server-Sent Events - برای streaming پاسخ AI |
| **JWT** | JSON Web Token - توکن احراز هویت |
| **Cron** | زمان‌بندی اجرای خودکار با cron expression |
| **Snapshot** | نسخه منجمد workflow هنگام شروع فرایند |
| **Context** | داده‌های جمع‌آوری‌شده در طول اجرای فرایند |
| **OCR** | Optical Character Recognition - استخراج متن از تصویر |
| **RTL** | Right-to-Left - راست‌به‌چپ (برای فارسی) |
| **Jalali** | تقویم شمسی ایرانی (هجری شمسی) |
| **SLA** | Service Level Agreement - توافق سطح سرویس (مهلت زمانی) |
| **Seed** | داده‌های اولیه برای راه‌اندازی سیستم |
| **advance_process** | تابع اصلی engine برای پیشروی فرایند |
| **evaluate_rule** | تابع ارزیابی شرط لبه |
| **inject_variables** | جایگزینی `{{var}}` در متن با مقادیر context |
| **BaseDocument** | کلاس پایه همه document‌های MongoDB |

## وضعیت‌های فرایند (Process Status)

| وضعیت | توضیح |
|-------|-------|
| `running` | در حال اجرا، تسک‌های فعال وجود دارند |
| `completed` | فرایند به node `end` رسیده |
| `rejected` | یک تسک رد شده و فرایند متوقف شده |
| `stuck` | خطای AI/OCR غیرقابل برگشت |

---

## وضعیت‌های تسک (Task Status)

| وضعیت | توضیح |
|-------|-------|
| `waiting` | منتظر تکمیل تسک‌های وابسته (dependencies) |
| `pending` | در صف انجام، به assignee اختصاص داده شده |
| `in_progress` | کاربر شروع به کار کرده (seen_time ثبت شده) |
| `approved` | تایید شده (برای approval node) |
| `rejected` | رد شده (فرایند متوقف می‌شود) |
| `done` | تکمیل شده (برای task/form node) |

---

## وضعیت‌های فرایند (Workflow Status)

| وضعیت | توضیح |
|-------|-------|
| `draft` | در حال طراحی، قابل اجرا نیست |
| `published` | منتشر شده، قابل اجرا |
| `archived` | آرشیو شده، قابل اجرا نیست |

## نقش‌های کاربری

| نقش | دسترسی‌های اصلی |
|-----|----------------|
| ادمین سازمان | مدیریت کاربران، دپارتمان‌ها، تمام قابلیت‌ها |
| طراح فرایند | ساختن/ویرایش workflow، form، مشاهده analytics |

## کلیدها و شناسه‌ها

| کلید | نوع | مثال | کاربرد |
|------|-----|------|--------|
| `id` | UUID4 string | `"3f2c9b1a-..."` | شناسه همه document‌ها |
| `org_id` | UUID4 string | `"5a7e2d8f-..."` | شناسه سازمان (tenant) |
| `created_at` | ISO datetime | `"2026-07-20T17:00:00+00:00"` | زمان ایجاد (UTC) |
| `updated_at` | ISO datetime | `"2026-07-20T18:00:00+00:00"` | آخرین بروزرسانی (UTC) |
| `JWT_TOKEN` | Bearer token | `"eyJhbGc..."` | در localStorage با کلید `jaryan_token` |

## Cron Expression راهنما

```
┌─────────── دقیقه (0-59)
│   ┌──────── ساعت (0-23)
│   │  ┌────── روز ماه (1-31)
│   │  │  ┌──── ماه (1-12)
│   │  │  │  ┌── روز هفته (0-6, 0=یکشنبه)
│   │  │  │  │
*   *  *  *  *

مثال‌ها:
0 9 * * 1-5    → هر روز کاری ساعت ۹:۰۰
0 * * * *      → هر ساعت
*/30 * * * *   → هر ۳۰ دقیقه
0 0 1 * *      → اول هر ماه میلادی
```
